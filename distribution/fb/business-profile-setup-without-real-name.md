# Facebook Presence for Wepho Without Using a Real Personal Name

Facebook's own rules require the underlying **personal account** to use your real/legal name (they periodically enforce this and can lock accounts asked to verify with ID). What you *can* legitimately do is keep the personal profile in the background and interact with the German wedding ecosystem through a **Facebook Page** (business identity) — the Page can be named "Wepho" and shows only the brand publicly.

The catch: Facebook groups (the highest-DAU surface — "Hochzeit 2026/2027", "Hochzeitsforum", regional groups) mostly do **not** let Pages join or post. You need a personal profile to join those. So the realistic setup is a hybrid.

Below are the two viable paths.

---

## Path A — Recommended: Real personal account (kept private) + public Wepho Page

This is the only path that is both ToS-compliant and gives you access to groups.

### 1. Personal account (kept minimal, used as the "operator")
- Use your real name. Set profile to maximum privacy:
  - Friends list → Only me
  - Posts → Only me / Friends
  - Profile picture and cover → keep neutral (a landscape, not your face) — profile photos are always public, but a landscape is fine
  - Turn off search-engine indexing (Settings → Privacy → "Do you want search engines outside of Facebook to link to your Profile?" → No)
  - Hide "About" fields (work, education, location, birthday) → Only me
- This account is essentially invisible. It exists so you can (a) own the Page and (b) join groups.

### 2. Create the Wepho Page
- facebook.com/pages/create → Category: **Local Business** or **Product/Service** → Name: **Wepho**
- Fill: short bio, website (wepho URL), contact email, WhatsApp/phone if desired, service area (Germany / DACH).
- Upload logo (profile) + a hero photo (cover).
- Publish 4–6 posts *before* doing outreach so the Page looks alive: photos of past events, one short "what we do" post, one testimonial, one "book a call" post.
- Turn on Messenger, set an auto-reply in German.
- Add a "Book Now" / "Contact Us" CTA button linking to your contact form.

### 3. Using the Page inside groups
- Facebook lets you **join groups as your Page** only in groups where the admin has enabled it (rare in German wedding groups). In most groups you'll be posting as your personal profile.
- When posting in a group as yourself, you can still **link to the Wepho Page** and add "Ich bin Gründerin von Wepho" in the post. That is allowed and normal.
- Never post the same promo copy across many groups in one day — Facebook's spam classifier will nuke the account. Space posts across days, vary wording, prefer *answering questions* over *posting offers*.

### 4. Optional: Business Manager / Meta Business Suite
- meta.com/business → create a Business Portfolio for Wepho, then move the Page inside it.
- Benefits: cleaner permissions, you can add a second admin later, unlocks Ads Manager, and separates Wepho assets from the personal profile.

---

## Path B — Persona / pen-name personal profile

Technically **against Facebook's Terms of Service** ("Provide accurate information about yourself"). Accounts can be locked and asked for government ID; if they fail verification, the Page they own can be orphaned. Only consider this if you have a real reason to keep your legal identity fully separated from Wepho (safety, privacy, etc.), and understand the risk.

If you do go this route:
- Use a plausible German name that isn't obviously fake (Facebook flags obvious pseudonyms).
- Warm the account for **at least 4–6 weeks** before doing anything commercial: add a phone number, add a few friends, post benign personal content, join non-wedding groups. New accounts that immediately promote a business are the #1 trigger for review.
- Do not use a VPN or a fresh browser profile with no cookies for signup — both raise the risk score.
- Use a phone number you control and can receive SMS on for verification (a real German prepaid SIM is safest; Google Voice / VoIP numbers are increasingly rejected).
- Profile photo: an AI-generated or stock face is a giveaway on reverse image search. A neutral photo (landscape, back-of-head, cropped hands) is safer.
- Expect that Facebook may still request ID verification at any time (often triggered by: joining many groups fast, posting links, being reported). If that happens, the account is effectively lost — plan for it.
- Never link the persona account to your real account (no shared devices without clearing cookies, no shared IP without care, no cross-friending).

Recommendation: **don't do this.** Path A gives you the same public-facing brand (a Wepho Page) with none of the enforcement risk, at the cost of your real name existing on a locked-down personal profile that nobody will ever look at.
