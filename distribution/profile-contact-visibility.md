# Contact info visibility in Reddit, Instagram, Pinterest profiles

Quick reference for whether emails / phone numbers / other contact details are typically exposed on public profiles — relevant for outreach planning (can you DM? do you need to scrape? is there a public email?).

---

## Reddit

- **Email:** Never public. Not shown on profiles, not searchable, not exposed via the API. Users register with email but it's private.
- **Phone:** Never public. Optional for 2FA only.
- **Real name:** Not required, not shown. Reddit is pseudonymous by default.
- **Bio ("About"):** Free-text field up to 200 chars. Users *sometimes* paste an email, Linktree, or personal site here — but it's rare and usually only for creators/OF/artists/small businesses. Wedding-adjacent users almost never do.
- **DMs / Chat:** The only reliable contact channel. Both "Chat" (real-time) and "Messages" (inbox) work by default unless the user disabled them.
- **Practical takeaway:** For Reddit outreach, plan on DMs. Don't expect to scrape emails.

---

## Instagram

- **Email:** Sometimes public — but only on **Business** and **Creator** accounts, and only if the user opted to display a "contact button." Personal accounts never expose email publicly.
  - When shown, it appears as an "Email" action button on mobile (not always visible on web).
  - Wedding vendors (photographers, planners, florists, venues) very commonly expose email this way. Couples and guests almost never do.
- **Phone:** Same rule as email — Business/Creator only, opt-in "Call" button. Common for vendors, rare for individuals.
- **Physical address:** Business accounts can display a mappable address. Common for venues.
- **Bio (150 chars):** Users frequently drop a Linktree, personal site, or "DM for inquiries" here. This is the most reliable public signal.
- **Website field:** Single clickable URL slot. Vendors almost always use it.
- **DMs:** Open by default from anyone unless restricted; message requests land in a separate inbox.
- **Practical takeaway:** For vendor outreach on IG, emails are often scrapeable from Business profile pages. For couples, you'll need DMs.

---

## Pinterest

- **Email:** Never public on the profile. Not displayed, not exposed via the standard API.
- **Phone:** Never public.
- **Real name / display name:** Shown (users usually use real names — Pinterest skews less pseudonymous than Reddit).
- **Bio ("About"):** Short free-text (~160 chars). Business accounts occasionally list a contact email here, but it's uncommon.
- **Website field:** Claimable website URL — very common for business accounts (wedding planners, photographers, stationery designers all use this). Personal users sometimes link a blog.
- **Location:** Optional free-text city/region field.
- **DMs:** Pinterest messaging exists but is weak and under-used — most users don't check it. Not a reliable outreach channel.
- **Practical takeaway:** For Pinterest, treat the **website link** as the main jumping-off point — click through to the vendor's own site to find their email. Don't rely on Pinterest DMs.

## Summary table

| Field | Reddit | Instagram | Pinterest |
|---|---|---|---|
| Email visible on profile | No | Business/Creator only (opt-in) | No |
| Phone visible on profile | No | Business/Creator only (opt-in) | No |
| Real name | No | Optional | Usually yes |
| Bio free-text | Yes (rare contact info) | Yes (common: Linktree, "DM me") | Yes (uncommon contact info) |
| Website link | Not really | Yes (single slot) | Yes (claimable) |
| DMs as outreach channel | Strong | Strong | Weak |

---

## Implications for Wepho outreach

- **Couples** (personal accounts across all three): no public emails. Reach them via Reddit DMs, IG DMs, or comments — not scraped contact info.
- **Wedding planners & vendors** (Business accounts on IG, claimed accounts on Pinterest): often have a public email button on IG and a website link on Pinterest that leads to their contact page. These are legitimately scrapeable at scale.
- **Reddit** is DM-only for outreach — no scraping shortcut exists.
