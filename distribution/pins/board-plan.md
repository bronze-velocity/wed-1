# Pinterest Board Plan — Wepho

10 boards, each mapped to a vibe/moment axis from `zz/wed-apps/20-apps.json` `_meta` (vibes, moments, feelings). Editorial titles first, keyword-heavy descriptions second — Pinterest search rewards the description, humans click the title.

Every board:
- **Description**: 200–500 chars, keyword-rich, natural. Include 2–3 primary keywords (e.g. "wedding reception games", "cocktail hour ideas") plus the emotional hook.
- **Cover-image direction**: what the featured 6-tile cover should evoke. All covers should share warm ambient lighting, real photography over stock, and one unmistakable "phone in the moment" element so a scroller can decode Wepho's category in one glance.
- **Feeds from**: which `app_slug`s should have the 3 drafted pins pinned to this board. An app can (and should) live on multiple boards where it fits; use the different pin variants (emotional / mechanics / SEO) to avoid pinning the same pin to the same board twice.

Coverage check at the end confirms every one of the 13 live apps sits on ≥2 boards.
