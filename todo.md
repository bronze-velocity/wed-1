 Per app:                                                                    
  1. Visit http://localhost:3000/dev/phone/<slug> — renders just the upright
  phone, transparent page background.                                         
  2. Open DevTools → Elements → find #phone-target → right-click → Capture 
  node screenshot. That gives you a perfectly-cropped PNG with transparent  
  margins.                                                                    
  3. Save to public/images/apps/phones/<slug>.png.
  Tip: bump DevTools DPR to 2 (Device Toolbar → "Add device pixel ratio" → 2) 
  before snapping, so the PNGs are retina-crisp.
